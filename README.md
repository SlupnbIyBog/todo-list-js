* Todo List

Небольшое приложение для ведения списка задач. Здесь можно добавлять задачи, отмечать их выполненными, изменять и удалять. Все задачи сохраняются в браузере, поэтому после обновления страницы они не пропадают.

* Что умеет приложение

- добавлять новые задачи;
- отмечать задачи выполненными;
- редактировать задачи;
- удалять задачи;
- искать задачи по названию;
- смотреть все, активные или выполненные задачи;
- удалять все выполненные задачи;
- показывать количество оставшихся задач;
- сохранять список задач после перезагрузки страницы.

* Используемые технологии

- HTML
- CSS
- JavaScript
- LocalStorage
